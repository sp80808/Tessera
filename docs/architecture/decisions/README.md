# Architecture Decision Records

Use ADRs for implementation architecture decisions that should remain discoverable after code changes.

Naming:

```
0001-short-title.md
0002-next-decision.md
```

Each ADR should contain:
- status;
- date;
- context;
- decision;
- alternatives considered;
- consequences;
- evidence/benchmarks;
- conditions that would justify reversal.

Language-design decisions normally belong in RFCs; implementation architecture belongs here.
